## 1. GRUNDLÄGGANDE INFORMATION

### Kursinformation

| Fält | Beskrivning | Ditt innehåll |
|------|-------------|---------------|
| **Kurstitel** | Kursens officiella namn (visas överallt) | |
| **Kurs-kod (slug)** | URL-vänligt namn (t.ex. "functional-energy") | |
| **Kort beskrivning** | 1-2 meningar som sammanfattar kursen | |
| **Målgrupp** | Vem passar kursen för? | |
| **Nivå** | Nybörjare / Medel / Avancerad | |
| **Längd (veckor)** | Antal veckor kursen pågår | |

### Exempel:
```
Kurstitel: Functional Energy
Kurs-kod: functional-energy
Kort beskrivning: Lär dig stabilisera blodsockret och få jämn energi hela dagen.
Målgrupp: För dig som har prediabetes, typ 2-diabetes eller vill förebygga blodsockersvängningar.
Nivå: Medel
Längd: 6 veckor
```

## 10. CHECKLISTA FÖRE PUBLICERING

### Grundläggande
- [ ] Kurstitel och beskrivning är ifyllda
- [ ] Pris är satt korrekt
- [ ] Nivå och längd stämmer

### Media
- [ ] Omslagsbild är uppladdad (rätt storlek)
- [ ] Intro-video fungerar och är korrekt länkad
- [ ] Välkomstmeddelande är skrivet

### Innehåll
- [ ] Alla veckor har kompletta måltidsplaner
- [ ] Alla recept finns i systemet
- [ ] Alla kunskapsdokument är skapade och länkade
- [ ] Inköpslistor genereras korrekt

### Produktsida
- [ ] Detaljerad beskrivning är skriven
- [ ] Kursmål och funktioner är listade
- [ ] SEO-metadata är ifylld

### Tekniskt
- [ ] Mailchimp-tagg är skapad
- [ ] Testat köpflödet (testbetalning)
- [ ] Kurs visas korrekt i kundens dashboard

### Kvalitetssäkring
- [ ] Testat kursen i förhandsgranskningsläge
- [ ] Kontrollerat att alla länkar fungerar
- [ ] Kollega har granskat innehållet
- [ ] Stavning och grammatik är kontrollerad
